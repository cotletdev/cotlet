# Security policy

This repository holds documentation only. To report a security issue in Cotlet (the website, the MCP server, the REST API or the console at cotlet.dev), email **[contact@cotlet.dev](mailto:contact@cotlet.dev)** with the subject "Security". The same contact is published in [cotlet.dev/.well-known/security.txt](https://cotlet.dev/.well-known/security.txt).

Please include what you found, the steps to reproduce it and the URLs or endpoints involved. Do not access other users' data, and give us reasonable time to fix the issue before you disclose it.

How Cotlet protects user accounts: [docs/security.md](docs/security.md) and [cotlet.dev/security](https://cotlet.dev/security).
