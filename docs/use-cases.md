# Cotlet use cases

[← Back to README](../README.md) · Live list: [cotlet.dev/use-cases](https://cotlet.dev/use-cases)

A use case is one job you hand to your AI agent in an app that has no usable API: approve members, schedule a post, reply to reviews, export a report, move bookings. Cotlet documents **591 jobs across 192 apps**. Each page explains what the app offers by itself, the steps, the tools your agent calls and how to run the job on a schedule.

## Jobs people hand to their agent, by audience

| Who | Typical jobs |
|---|---|
| **Community owners and creators** | Approve membership requests, welcome new members, post updates, reply to comments and DMs, schedule newsletter posts, pull engagement stats |
| **Course sellers** | Create coupons, send announcements, update lectures, reply to student comments, export revenue reports |
| **Tour operators and hosts** | Update availability and pricing, list bookings, reply to guests and reviews, export payouts |
| **Real estate pros** | Update and renew listings, reply to leads, export comps and saved searches, post rent charges, create work orders |
| **Salons, studios and local services** | Create and reschedule appointments, manage waitlists, reply to clients, export daily sales |
| **Field service and trades** | Schedule jobs, create invoices and change orders, write daily logs, record payments |
| **Freelancers and agencies** | Send proposals, contracts and invoices, read form responses, run the same job across many client accounts |
| **Developers** | Call any of these jobs from a script or cron job over the REST API, with one key |
